# AllowayAI browser demo

Open `index.html` in a browser to explore the sports analytics examples. The page contains the controls and calculations. The separate [allowayai R package](https://github.com/ianalloway/allowayai) implements the R library.

For a local web server, run `python3 -m http.server 8000 --bind 127.0.0.1` from the repository root and open `http://localhost:8000`.
